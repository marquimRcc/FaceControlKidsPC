# docs/archive — Documentação Legada

Este diretório contém documentos históricos de exploração, homologação e handoffs que foram **supersedidos** pela especificação canônica em `specs/producao-windows/`.

> [!NOTE]
> Estes arquivos são preservados como referência histórica. Não os use como fonte de verdade para o estado atual do sistema.

## Conteúdo

### `pocs/` — Provas de Conceito (POC-001 a POC-042)
Experimentos técnicos de viabilidade executados durante o desenvolvimento inicial. Cobrem tópicos como:
- Webcam na sessão bloqueada (POC-001)
- Credential Provider C++ (POC-002)
- SID Binding do Named Pipe (POC-004)
- Biometria 1:N e política (POC-012)
- Câmera USB e hardware acceptance (POC-013/018/026/028/040)
- Liveness trust boundary (POC-029)

### `handoffs/` — Relatórios de Homologação, Handoffs e Laboratório
Relatórios de sessões de trabalho, handoffs entre IAs, homologações em VM e roteiros de laboratório. Incluem:
- Homologações de VM (SCM Writer, Webcam, WTS)
- Relatórios de broker e cutover
- Roteiros de developer (P0 a P6)
- Análises de Regata OS / Linux
- Documentos de transição e progresso autônomo
